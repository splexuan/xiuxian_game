# 仙途 · 挂机修仙录

一款**纯前端、零依赖**的浏览器挂机修仙游戏。打开网页即可开玩，进度自动保存在本地。

水墨仙侠视觉 × 深度数值成长 × 十三重境界 × 神通战斗 × 锻炉合成 × 寻宝抽卡 × 飞升转生。

---

## 快速开始

**方式一：直接打开（最简单）**

双击 `index.html` 即可开始游玩。

**方式二：本地服务器（推荐，兼容性最好）**

```bash
node server.js          # 默认 http://localhost:8080
node server.js 9000     # 指定端口
```

> 游戏本身不需要任何安装、编译或联网。`server.js` 只是一个 40 行的静态文件服务器，方便在局域网/手机上访问。

进入游戏后会自动切到 **「道途」** 面板 —— 跟着它一步一步走，很快就能上手。

## 玩法系统

### 一、修行与境界
`练气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫 → 地仙 → 天仙 → 金仙 → 大罗`

13 重大境界 × 9 层小境界。小境界突破有成功率，跨越大境界必须**渡天劫**——那是一场真刀真枪的战斗。
点击中央灵珠可「吐纳」手动加速。

### 二、道途（分步引导 + 任务链）
**这是解决「不知道该干嘛」的核心系统。**
6 章共 36 步任务，从「点击灵珠吐纳三次」一路引导到「飞升三次、踏上大罗」。
- 每一步都有明确的**目标、提示与奖励**
- 达成后左下角追踪条会发光，回到面板点「领取」即可
- 奖励包含仙玉、装备、宝石、灵材，以及**永久属性加成**

### 三、神通与战斗（主动操作）
战斗不再是纯数值对撞：

| 机制 | 说明 |
|------|------|
| **灵力条** | 每回合积攒灵力，满则释放神通 |
| **14 门神通** | 裂石拳 / 御剑术 / 焚天诀 / 金光罩 / 大道湮灭…… 分攻击、增益、减益、治疗四类 |
| **三种姿态** | 均衡 / 攻势（攻 +40%、防 −30%）/ 守势（防 +75%、受伤 −22%），战斗中随时切换 |
| **蓄力预警** | 妖王会喊出「正在蓄力，下一击重创」，此时切守势或开护体技可保命 |
| **连击系统** | 连续命中共叠加 10 层连击，每层 +3% 伤害；被击中则清零 |
| **战斗中服丹** | 服丹不占用行动，为关键时刻续命 |
| **手动 / 自动应战** | 右上角一键切换。挂机时自动施法，想秀操作就切手动，按 `1/2/3` 键放神通 |

**神通配置**：在「功法」页有 3 个神通位，随境界解锁更多选择，可手动配置或一键自动装配。

### 四、锻炉（合成 / 强化 / 镶嵌）
| 功能 | 说明 |
|------|------|
| **强化** | +1 ~ +15，每级提升该装备全部属性 10%；等级越高成功率越低 |
| **三合一升品** | 3 件同部位同品阶 → 1 件更高品阶，并继承部分强化等级 |
| **词条重铸** | 随机重洗副属性（有保底，不会越洗越差） |
| **宝石镶嵌** | 品质越高孔位越多（最高 3 孔），10 种宝石提供额外词条 |
| **宝石 / 灵材合成** | 3 颗同阶宝石 → 1 颗更高阶（数值 ×1.9）；灵材同理 |

### 五、寻宝阁（抽卡 + 保底）
四座独立的池子，各有**独立保底计数**：

| 池 | 消耗 | 产出 | 保底 |
|----|------|------|------|
| 问道池 | 仙玉 | 未习得的功法 | 每 10 抽必得灵品以上 |
| 寻宝池 | 仙玉 | 高品阶装备（含套装） | 每 20 抽必得玄品以上 |
| 御兽池 | 仙玉 | 未拥有的灵宠 | 每 15 抽必得新灵宠 |
| 采药池 | 灵石 | 灵草 / 灵材 / 宝石 | 每 10 抽必得宝石 |

十连享折扣，并有**逐张翻开的全屏结果展示**。

### 六、装备与掉落
- **随机词条**：10 类词条（攻击/防御/气血/暴击/爆伤/闪避/速度/吸血/穿透/修炼）随机生成
- **套装共鸣**：凡铁 / 灵纹 / 玄天 / 太乙 / 神魔 / 鸿蒙，集齐 2 件 / 4 件激活额外效果
- **掉落弹窗**：宝品以上的战利品会弹出品质光效卡片

### 七、秘境（随机遭遇）
26 个区域，每 6 秒结算一次。**24% 概率触发随机遭遇**：
上古宝箱 / 秘境灵泉 / 悟道石 / 宝石矿脉 / 灵草园 / 禁制陷阱 / 游方商人 / 精英妖兽。
另有小概率遭遇**妖王**（真实战斗，掉落丰厚）。

### 八、天象
每隔约 15 分钟降临一次天地异象，持续 7 分钟：
灵气潮汐（灵气 +55%）/ 星辰垂芒（灵石 +80%）/ 道韵流转（突破 +15%）/ 天雷淬体（掉落 ×2）/
血煞冲霄（攻 +60%、灵气 −20%）/ 仙缘汇聚（仙玉 ×2）/ 天道无情（灵气 −35%）/ 煞气弥漫（妖敌 +25%）。
顶栏会显示当前天象与剩余时间。

### 九、洞天 / 功法 / 丹道 / 灵宠
- **洞天**：11 种建筑，消耗灵石永久增益
- **功法**：28 门分四类（心法/攻伐/护体/身法），六个品阶
- **丹道**：8 种丹药（即时回灵 / 限时增益 / 永久提升）
- **灵宠**：10 种，孵化培养，提供永久被动加成

### 十、通天塔
无限层挑战，难度按指数增长。每层必掉装备，**每 5 层必掉高品装备**，另有仙玉、灵材与宝石。
这是贯穿全部转生周期的长线标尺。

### 十一、奇遇 · 道果 · 飞升
- **奇遇**：10 类随机事件，部分需要**做出抉择**，代价与收益并存
- **道果**：28 项成就，提供跨越飞升的永久加成
- **飞升**：修至**大乘境**可转生。**保留**仙缘点、仙缘天赋、道果、灵宠、宝石、锻炉积累；**重置**境界、灵气、灵石、洞天、功法、装备、塔层

## 界面与操作

界面分四区：**顶栏**（境界 / 灵气 / 天象 / 资源）、**左侧导航**（按「修行 · 成长 · 征战 · 归藏」分组）、
**主内容区**、**右侧天机录**（可收起，把空间让给主界面）。

| 位置 | 说明 |
|------|------|
| 顶栏 | 点击资源可直达对应用途面板（灵石→洞天、灵草→丹道、仙玉→寻宝阁） |
| 中央 | 点击灵珠「吐纳」；「运功突破」推进境界 |
| 底栏「道途」入口 | 显示当前目标与进度，达成时高亮脉冲；点击进入道途面板 |
| 修炼页「下一步」 | 当前道途 + 可领取按钮 + 最多 3 条情境提示 |
| 天机录 | 可按 全部 / 战斗 / 收获 / 机缘 筛选；右上「收起」可折叠 |
| 底栏开关 | 自动突破、自动丹药、自动秘境 |
| 战斗浮层 | 1×/2×/4×/8× 倍速、姿态切换、神通释放（`1/2/3` 键）、服丹 |
| 装备卡 | 每件装备都有「锻造」按钮直达锻炉 |

> 引导做成三层（底栏入口 → 修炼页下一步卡片 → 道途面板），
> 都**不遮挡游戏内容**，取代了早期那种常驻浮动的提示框。
>
> 想纯挂机：开启三个开关 + 保持战斗「自动应战」即可。
> 想拔尖：手动切姿态、卡蓄力预警、关键时刻服丹，能打过更高层的塔。

### 移动端

页面采用**整屏 flex 纵向布局**（顶栏 / 主体 / 底栏自适应分配高度），不再用 `calc()` 硬算，
因此顶栏换行、底栏加高都不会错位。

| 断点 | 变化 |
|------|------|
| ≤1280px | 收窄左右两侧栏 |
| ≤1100px | 隐藏天机录，空间全给主内容 |
| ≤900px | **导航改为全展开网格**（13 个入口一屏呈现，不藏不滚）；顶栏换行、灵气条独占一行；战斗浮层贴底全宽；神通按钮改为大号块状；弹窗接近全屏 |
| ≤620px | 底栏做减法：只留「战力」+ 三个图标开关；网格降为单列；简化顶栏与卡片内边距 |
| ≤380px | 进一步压缩道途入口与资源栏 |
| 矮屏横屏 | 顶栏压扁、灵珠缩小、战斗日志限高 |

> **导航为什么不横滑？**
> 早期版本在移动端把侧栏做成横向滚动条，还把滚动条隐藏了。
> 结果 13 个入口有 8 个被推到屏幕外，且没有任何可滑动提示，
> 玩家会误以为「底部就这么几个功能」。
> 现在改为自适应网格，全部入口一屏铺开——宁可多占一点高度，也不隐藏功能。

### 战斗浮层的尺寸约束

战斗浮层是 `position:fixed` + `bottom` 贴底定位的，**内部任何元素增高或塌缩，
都会让上方内容整体跳动**。因此浮层内所有会变化的区域都必须「预留位置」：

| 区域 | 做法 | 原因 |
|------|------|------|
| 战斗日志 | `height` 固定（桌面 190px / 移动 120px） | 用 `max-height` 会随行数从 0 撑到上限，整个面板一回合长高一次 |
| 战况提示条 | `height:62px` 固定 + 隐藏时 `visibility` | 它在「轮到你出手 / 敌方蓄力」间每回合切换，用 `display:none` 会让下方跳动 |
| 增益徽章 | `height:26px` + `flex-wrap:nowrap` + 横向滚动 | 原来是换行，多一个徽章就把两侧信息栏撑高 |
| 神通行 | `flex-wrap:nowrap` + 横向滚动 | 神通过多时换行会把指令区撑成两行 |
| 神通消耗 | `min-width:52px` | 「灵力 N」变「冷却 N」时按钮宽度抖动，整排神通重排 |
| 头部 | 拆成「标题段 + 控制段」，移动端各占整行 | 混在一起自动折行时，标题一长就多折一行（实测 115px ↔ 144px 跳变） |
| 结算条 | 高 68px，由日志让出 `calc(<日志高> - 79px)` | 两者等量置换，浮层总高不变 |

`tests/css-audit.js` 对以上每一条都有断言，`npm test` 会拦截退化。
> 这一条已写成断言（`tests/css-audit.js`），防止再次退化。

所有可点元素在移动端满足 **≥44px** 触控高度，并适配刘海屏安全区（`viewport-fit=cover` + `env(safe-area-inset-*)`）。

### 设计系统

所有颜色与字号收敛为**设计令牌**，定义在 `main.css` 的 `:root`：

| 类别 | 令牌 | 说明 |
|------|------|------|
| 文本 | `--txt` / `--txt-2` / `--txt-dim` / `--txt-mute` | 四级信息层级，最弱一级仍有 **5.2:1** 对比度 |
| 背景 | `--glass` / `--surface` / `--surface-2` / `--sunken` | 高不透明度实底，避免粒子背景干扰阅读 |
| 字号 | `--fs-mini` ~ `--fs-2xl` | 12 / 12.5 / 13.5 / 14.5 / 16 / 20 / 26 px，**内容文字不低于 12px** |
| 圆角 | `--r-sm` / `--r-md` / `--r-lg` | 统一圆角 |

**这些约束由 `tests/css-audit.js` 自动校验**（见下），改样式时不会悄悄退化。

### 样式审计（`tests/css-audit.js`）

静态解析 `main.css`，把「好不好读 / 适不适配」变成可计算的断言：

- **WCAG 对比度**：解析 CSS 变量、把半透明层叠到实际底色上，逐个文本令牌 × 逐个背景面计算对比度
- **字号下限**：扫描所有 `font-size` 声明，任意小于 12px 即失败
- **布局健壮性**：强制 `body` 用纵向 flex、禁止 `#layout` 用 `calc()` 硬算高度
- **移动端适配**：要求 900px / 620px 两档媒体查询存在，并校验其中侧栏转横向、
  触控高度 ≥44px、底栏精简、战斗浮层全宽等关键改动仍在
- **安全区**：校验 `viewport-fit=cover` 与 `env(safe-area-inset-*)` 的使用

当前实测（最差情况即最亮的区块底色）：

```
--txt       11.79:1   ✓      --txt-dim    6.54:1   ✓
--txt-2      9.12:1   ✓      --txt-mute   5.20:1   ✓   ← 最弱一级仍远超 AA 的 4.5:1
```

跑一下 `npm run test:css` 就能看到完整的对比度矩阵。

### 逻辑测试（`tests/smoke-test.js`）

在 Node 沙箱中加载全部逻辑层脚本，驱动一个**接近最优策略的自动游玩 AI** 长时间运行。
该 AI 会领任务、建洞天、修功法、抽四个池子、合成装备、镶嵌宝石、配神通、爬塔、飞升。校验：

- 无异常抛出、无数值溢出（NaN / Infinity / 负数）
- 存档读写往返一致、离线结算可用
- **节奏契约**：抵达飞升门槛耗时落在设计区间内
- **通天塔可爬升深度**落在设计区间内

当前基线（2 小时自动游玩，多次运行区间）：

| 里程碑 | 耗时 |
|--------|------|
| 筑基 | 5 ~ 17 分 |
| 金丹 | 7 ~ 22 分 |
| 元婴 | 11 ~ 26 分 |
| 化神 | 15 ~ 30 分 |
| 炼虚 | 19 ~ 34 分 |
| 合体 | 21 ~ 40 分 |
| **大乘（飞升门槛）** | **44 ~ 62 分** |
| 大罗（满级） | 48 ~ 66 分 |
| 通天塔可达 | 50 ~ 100 层 |

> 自动 AI 每 4 秒决策一次且永远选最优解，**真人玩家的实际节奏通常是上表的 2~4 倍**。

## 调参指南

所有平衡参数集中在三个地方：

| 文件 | 内容 |
|------|------|
| `data/realms.js` → `XG.CONFIG` | 层内成长率、突破成功率、天劫、离线效率、飞升门槛、造价系数等 |
| `data/realms.js` → `XG.REALMS` | 13 重境界的灵气需求、境界乘数、基础攻防 |
| `data/content.js` / `content2.js` | 各系统的具体数值、造价、掉落权重 |

关键平衡原则（改动时请保持）：

1. **两个全局节奏闸门**：层内成长 `LAYER_EXP_GROWTH = 1.70`（决定单个大境界的基准耗时），
   境界比 `q = expBase增长 / realmMult增长 ≈ 2.0`（决定大境界之间的相对长度）。
   新增会放大战力的系统时，必须同步调高 `LAYER_EXP_GROWTH`，否则一局会被打穿。
2. **造价随境界增长（`REALM_COST_MULT = 19`）**：略高于灵石收入增长率，使投入始终吃紧；
   飞升回落后重建轻快——这是转生循环的核心手感。
3. **同类型加成加算、跨类型相乘**：避免多个线性项相乘造成超指数膨胀。
4. **功法与灵宠的聚合加成取 `1 + raw^0.7`**：保留「持续堆叠」的快感，但不至于指数爆炸。
5. **天劫强度由玩家实力反解**：通过解 `3x² - 3Mx - MD = 0` 得到敌方攻击力，保证「需全力应对但准备充分即可取胜」。
6. **消耗用「N 秒收入」表达**：锻炉与任务奖励都以 `Combat.stoneUnit()` 为基准，
   使任何境界下的投入体感一致。
7. **仙缘加成必须收敛**：`Calc.mods()` 里的 `prSpirit/prAtk/prHp` 走 `Calc.permRate()`
   （`1 + per * min(n, 800)^0.72`，上限约 ×9.5），**不能用线性**。
   境界需求是固定的，加成若随 `earned` 无限增长，转生若干次后单局时长会塌缩，
   13 重境界的内容会被一路秒穿。`Prestige.preview()` 必须与 `mods()` 用同一公式。
8. **速度的收益是有界的**：实际收益 = 先手判定 + 灵力回复倍率
   （按双方速度比映射到 `SPD_ENERGY_MIN ~ SPD_ENERGY_MAX`，即 0.6~1.8）。
   因此 `Calc.power()` 里的速度项必须同步封顶，否则无上限堆速度会把战力虚抬，
   显示强度与实际战斗力脱节。

修改后请务必运行 `npm run test:logic`，确认节奏契约断言仍然通过。

## 兼容性

- Chrome / Edge / Firefox / Safari 近两年版本
- 无任何构建步骤、无外部 CDN、无网络请求
- 响应式：窄屏自动收起侧栏与日志栏，导航移到底部
- 存档位于 `localStorage` 的 `xiantu_save_v1` 键；若存储不可用，游戏会降级为「不保存」并继续运行
